# Gallery

Drop images here. For each image, add a `.txt` file with the **same base name** containing the caption.

Examples:
- `image1.jpg` + `image1.txt`
- `sunset.png` + `sunset.txt`
- `IMG_2381.jpeg` + `IMG_2381.txt`

Supported image extensions: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.heic`, `.bmp`, `.tiff`.

The caption file is plain text — write whatever fancy caption you want. If a caption file is missing, the filename is used as a fallback.
